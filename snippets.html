Flex Basics

SantyCSS uses make-flex as the base flex class. Combine it with direction, alignment, gap, and wrap helpers to build any layout.

Horizontal Row
Arrange items side-by-side with a gap.
make-flex · gap-*
Preview
Item A
Item B
Item C
HTML 
<div class="make-flex gap-12">
  <div>Item A</div>
  <div>Item B</div>
  <div>Item C</div>
</div>

<!-- Available gap sizes: gap-4 gap-8 gap-10 gap-12 gap-16 gap-20 gap-24 gap-32 -->

# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| < 2.0 | No |

## Reporting a vulnerability

SantyCSS is a static CSS framework with no runtime dependencies, but the JIT engine,
CLI, and build tooling do execute JavaScript. If you find a security issue, please
email **hello@santy.in** — do not open a public issue. You will receive a response
within a few days, and a fix will be released as soon as possible.
